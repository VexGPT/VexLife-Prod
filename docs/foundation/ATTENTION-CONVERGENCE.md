# VexLife Attention Convergence — perceptibility + activity-scoped nomination

`[VXG RealForever]`

## Human question

How can Vex remain connected to many independently-owned truths without copying every connected
source body into present cognition?

A1 answers only the first reusable relationship:

```text
rightful source owner
  owns domain meaning + source currentness
        ↓
small source-addressed candidate
  preserves owner/source/relationship/currentness/standing/reopen coordinates
        ↓
later cognition may decide whether deeper source is useful
```

This is a read-only source relationship. It grants no effect and performs no source read.

## VexArchitecture placement

A1 is not a mandatory pipeline stage and not a new truth owner for connected sources.

```text
SOURCE / FAMILY / PARTNER OWNER
  owns the source meaning

ATTENTION PERCEPTIBILITY
  owns only the bounded candidate relationship

DIRECT PROMPT CONTEXT
  still owns provider materialization

CAPABILITY / SOURCE OWNER
  still owns exact deeper source reopening

SELF-INSPECTION / HUMAN PRESENTATION
  may later project the same relationship
  but do not arbitrate it
```

This follows the VexArchitecture convergence law:

> new relationship truth may be owned without re-owning its independently-owned inputs.

Attention Convergence is therefore earned only where the relationship to present cognition becomes
a real question. A source does not need an Attention wrapper merely to exist.


### Why both source meaning and perceptibility standing exist

`sourceStandingRef` stays opaque to Attention. It belongs to the source/domain owner.

`reachability` answers only whether the exact deeper-source coordinate can currently be followed:

```text
REACHABLE
HELD
UNAVAILABLE
UNKNOWN
```

The two must not collapse.

```text
DOMAIN STANDING != REOPEN REACHABILITY
REACHABLE != EFFECT AUTHORITY
HELD != SOURCE DELETED
UNKNOWN != SOURCE ABSENT
```

### Exact source binding

`sourceBindingRefs[]` must be non-empty. The source owner supplies the exact version/currentness/
observation/receipt coordinates that bind the compact candidate to current source truth.

Attention does not interpret those refs into one universal currentness model.

```text
SOURCE BINDING REFS
!= GLOBAL SOURCE VERSION SCHEMA
!= ATTENTION-OWNED CURRENTNESS
```

### Deeper source

`deeperSourceRef` is only an address.

```text
DEEPER SOURCE REF
!= SOURCE CONTENT
!= CAPABILITY REQUEST
!= READ AUTHORITY
!= EFFECT PERMISSION
```

A later activity-convergence consumer must use the rightful existing source/capability owner to
reopen exact content.

### Compact meaning

A1 permits one owner-authored compact semantic meaning and enforces a small per-candidate ceiling.
That ceiling is an implementation guard for this candidate representation, not a global context
budget or a claim about the final many-connection operating envelope.

The exact aggregate quiet-cost/context envelope remains an A6 measurement question.

## Surface behavior

`form(...)` receives candidates from existing connection/topology/source owners. It does not
discover connections and is not a global registry.

The surface sorts by stable `candidateRef` only to make equivalent inputs deterministic.

```text
LEXICAL IDENTITY ORDER
!= RELEVANCE
!= URGENCY
!= PRIORITY
!= SOURCE SIGNIFICANCE
```

A1 deliberately performs no truncation or semantic selection across candidate population. A2 owns
the question of relating current human activity to quiet candidates. A6 owns the scale pressure that
may earn a more specific bounded candidate-discovery/index mechanism.

## Current-source relationships consumed

A1 is designed to compose with current Product relationships rather than replace them:

- Capability Atlas / Self-Frame already demonstrates compact current handles with deeper details kept
  outside the prompt;
- Continuity Source Locator demonstrates derived candidate coordinates that must exact-reopen
  canonical Conversation before content is exposed;
- Memory Hot Path demonstrates acceleration that may disappear without losing source truth;
- VexPartner demonstrates independently-owned Source / Signal / Connection meaning without lifting
  domain semantics into a universal owner;
- DirectPromptContext remains the exact provider materialization owner.

Those sources are architectural pressure/evidence. A1 does not make them children of one new
registry.

## A1 nonclaims

- define or consume Working Focus;
- define source-owned attention requirements;
- rank two sources;

- displace or resume work;
- insert anything into a provider prompt;
- create a notification;
- perform a source/capability read;
- mutate Memory or Conversation;
- grant an effect;
- create Health/CGM semantics;
- create a universal connected-source registry.

Those belong to later stages only when their exact relationship is earned.

## A2 activity-scoped convergence

A2 consumes A1 candidates without making the Activity or the candidate source into Attention-owned
truth.

```text
source-owned current activity
+ A1 perceptibility surface
+ bounded Vex/model candidate nomination
        ↓
validate exact activity binding
validate exact candidate source bindings
        ↓
nominated candidate refs + deeper-source addresses
quiet candidate refs remain reachable
        ↓
no source read yet
no effect authority
```

Current source:

```text
src/commonMain/kotlin/vexlife/attention/VexLifeAttentionActivityConvergence.kt
src/commonTest/kotlin/vexlife/attention/VexLifeAttentionActivityConvergenceTest.kt
```

### Activity is source-bound, not Attention-authored

A2 does not define the complete Product activity ontology. It accepts one bounded Activity coordinate
with exact `sourceBindingRefs[]`, optional subject scopes and an optional
`workingFocusRefOrNull`.

The optional Working Focus reference is important while Self-Inspection / Working Focus remains a
separate trajectory:

```text
WORKING FOCUS PRESENT
  -> preserve exact rightful-owner ref

WORKING FOCUS ABSENT / NOT LANDED
  -> null
  -> do not fabricate an Attention-owned substitute
```

### Model nomination is candidate cognition, not source truth

A2 does not implement a hard-coded semantic relevance scorer.

The selected model/Vex may form a bounded `Judgment` containing only candidate refs and the exact
activity/candidate source bindings it judged. No rationale or private reasoning is retained by this
contract.

```text
MODEL NOMINATION
!= SOURCE TRUTH
!= MEMORY ACCEPTANCE
!= PRIORITY
!= EFFECT AUTHORITY
```

The judgment must bind the current Activity and each selected candidate's current
`sourceBindingRefs[]`. A stale activity or stale candidate generation fails closed rather than
silently applying an old nomination to new source truth.

### Selection budget is supplied, not invented as global policy

A2 receives one caller/source-owned `SelectionBudget` with a positive-or-zero maximum selected
candidate count. It enforces that bound but does not claim the number is the universal Attention
operating envelope.

A6 still owns the lived many-connection/context-budget measurement.

### Quiet means quiet now

Candidates not selected by this activity judgment are returned as `quietCandidateRefs[]`.

```text
QUIET NOW
!= IRRELEVANT FOREVER
!= SOURCE ABSENT
!= SOURCE DELETED
!= UNREACHABLE
```

A later activity may judge the same source differently after exact currentness is re-bound.

### Reachability remains truthful

A relevant candidate may still be `HELD`, `UNAVAILABLE` or `UNKNOWN`. A2 may preserve that
nomination, but it cannot turn it into a successful read.

```text
NOMINATED + HELD
= relevant relationship recognized
!= source read
!= source returned
```

The rightful source/capability owner remains responsible for any later exact reopen.

### Cross-lane convergence laws

A2 is intentionally checked against current parallel architecture rather than treated as an isolated
Attention subsystem.

#### Long-Term Memory / LH-5

Memory Depth owns **historical source location and exact source reopening**. Its semantic nomination
work establishes an important law for Attention too:

```text
semantic resemblance / compact candidate signal
-> reason to inspect exact source
!= accepted meaning
!= final current relevance
```

A2 therefore owns **candidate nomination for deeper inspection**, not final semantic relevance.
The rightful source/capability owner must still reopen exact source before a later cognition stage
treats the source content as understood.

```text
ATTENTION NOMINATION != MEMORY RETRIEVAL
MEMORY SEMANTIC NOMINATION != ATTENTION
BOTH MAY SHARE:
  candidate -> exact source -> current judgment
```

Attention must consume that shape rather than build a second semantic index or source-retrieval
owner.

#### Multi-Vex / participant relationships

Current Product prompt law already says current context is current only for the owner/subject it
names. A2 therefore preserves and exact-binds both:

```text
Activity.subjectScopeRefs[]
Candidate.subjectScopeRefs[]
```

A nomination formed against one owner/subject binding cannot silently apply after those scopes
change.

Attention does **not** decide whether two subjects are equivalent, whether a counterpart may see
another subject's source, or whether one participant outranks another. Those remain with the
rightful relationship/privacy/source owners.

```text
SUBJECT SCOPE != PRIORITY
SUBJECT SCOPE != ACCESS GRANT
CURRENT FOR SUBJECT A != GLOBALLY CURRENT
```

#### Family-B / whole-body canary

Family-B is a downstream composition pressure, not an Attention semantic owner. Its lived builder
canary pressures Conversation, Memory, source re-entry, capability effects, context pressure,
restart and completion together.

Attention should eventually be included in a similarly whole-body lived proof once A3/A4 are stable,
but should not import the Family-B harness or model-reach ownership into Attention source.

```text
FAMILY-B CANARY = CONSUMER / PRESSURE SURFACE
!= ATTENTION OWNER
!= MEMORY OWNER
!= CAPABILITY OWNER
```
