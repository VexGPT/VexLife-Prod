# VexLife Attention Convergence — source-addressed perceptibility

`[VXG RealForever]`

## Human question

How can Vex remain connected to many independently-owned truths without copying every connected
source body into present cognition?

A1 answers only the first reusable relationship:

```text
rightful source owner
  owns domain meaning + source currentness
        ↓
small source-addressed candidate
  preserves owner/source/relationship/currentness/standing/reopen coordinates
        ↓
later cognition may decide whether deeper source is useful
```

This is a read-only source relationship. It grants no effect and performs no source read.

## VexArchitecture placement

A1 is not a mandatory pipeline stage and not a new truth owner for connected sources.

```text
SOURCE / FAMILY / PARTNER OWNER
  owns the source meaning

ATTENTION PERCEPTIBILITY
  owns only the bounded candidate relationship

DIRECT PROMPT CONTEXT
  still owns provider materialization

CAPABILITY / SOURCE OWNER
  still owns exact deeper source reopening

SELF-INSPECTION / HUMAN PRESENTATION
  may later project the same relationship
  but do not arbitrate it
```

This follows the VexArchitecture convergence law:

> new relationship truth may be owned without re-owning its independently-owned inputs.

Attention Convergence is therefore earned only where the relationship to present cognition becomes
a real question. A source does not need an Attention wrapper merely to exist.

### Why both source meaning and perceptibility standing exist

`sourceStandingRef` stays opaque to Attention. It belongs to the source/domain owner.

`reachability` answers only whether the exact deeper-source coordinate can currently be followed:

```text
REACHABLE
HELD
UNAVAILABLE
UNKNOWN
```

The two must not collapse.

```text
DOMAIN STANDING != REOPEN REACHABILITY
REACHABLE != EFFECT AUTHORITY
HELD != SOURCE DELETED
UNKNOWN != SOURCE ABSENT
```

### Exact source binding

`sourceBindingRefs[]` must be non-empty. The source owner supplies the exact version/currentness/
observation/receipt coordinates that bind the compact candidate to current source truth.

Attention does not interpret those refs into one universal currentness model.

```text
SOURCE BINDING REFS
!= GLOBAL SOURCE VERSION SCHEMA
!= ATTENTION-OWNED CURRENTNESS
```

### Deeper source

`deeperSourceRef` is only an address.

```text
DEEPER SOURCE REF
!= SOURCE CONTENT
!= CAPABILITY REQUEST
!= READ AUTHORITY
!= EFFECT PERMISSION
```

A later activity-convergence consumer must use the rightful existing source/capability owner to
reopen exact content.

### Compact meaning

A1 permits one owner-authored compact semantic meaning and enforces a small per-candidate ceiling.
That ceiling is an implementation guard for this candidate representation, not a global context
budget or a claim about the final many-connection operating envelope.

The exact aggregate quiet-cost/context envelope remains an A6 measurement question.

## Surface behavior

`form(...)` receives candidates from existing connection/topology/source owners. It does not
discover connections and is not a global registry.

The surface sorts by stable `candidateRef` only to make equivalent inputs deterministic.

```text
LEXICAL IDENTITY ORDER
!= RELEVANCE
!= URGENCY
!= PRIORITY
!= SOURCE SIGNIFICANCE
```

A1 deliberately performs no truncation or semantic selection across candidate population. A2 owns
the question of relating current human activity to quiet candidates. A6 owns the scale pressure that
may earn a more specific bounded candidate-discovery/index mechanism.

## Current-source relationships consumed

A1 is designed to compose with current Product relationships rather than replace them:

- Capability Atlas / Self-Frame already demonstrates compact current handles with deeper details kept
  outside the prompt;
- Continuity Source Locator demonstrates derived candidate coordinates that must exact-reopen
  canonical Conversation before content is exposed;
- Memory Hot Path demonstrates acceleration that may disappear without losing source truth;
- VexPartner demonstrates independently-owned Source / Signal / Connection meaning without lifting
  domain semantics into a universal owner;
- DirectPromptContext remains the exact provider materialization owner.

Those sources are architectural pressure/evidence. A1 does not make them children of one new
registry.

## A1 nonclaims

This source does **not** yet:

- choose candidates from current human activity;
- define or consume Working Focus;
- define source-owned attention requirements;
- rank two sources;
- acknowledge a claim;
- displace or resume work;
- insert anything into a provider prompt;
- create a notification;
- perform a source/capability read;
- mutate Memory or Conversation;
- grant an effect;
- create Health/CGM semantics;
- create a universal connected-source registry.

Those belong to later stages only when their exact relationship is earned.
