Release notes

Windows

In preparation

Not available yet. VexLife's local model runtime is built on Apple's MLX, which runs only on Apple silicon. A Windows realization needs its own model runtime and is being prepared; nothing is offered here until it exists and has been run on a real Windows PC.

    Versions

    Stable, preview, and how a version is made

    Stable

    Accepted

    A version (v0.6.0, v0.7.0…) is cut from main when a feature threshold has been lived and accepted. Each one is built from one exact commit.

    Preview

    Intentional

    A preview is published from main only when a newer build is worth sharing or testing. Merging a PR alone does not create a public download.
